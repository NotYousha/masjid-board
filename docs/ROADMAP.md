# Roadmap

Each item below is meant to become a GitHub issue. Items marked **good first issue** need no knowledge of the code.

## Languages (good first issue)
French, Turkish, Indonesian, Malay, Bengali, Somali, Persian, German, Spanish, Bosnian, Swahili, Hausa, Tamil, Pashto.

## Themes (good first issue)
- Light theme for bright halls with daylight on the screen
- High-contrast theme for older eyes
- Ramadan theme
- A theme in your masjid's own colours

## Features
- **Timetable file:** let a masjid upload its own timetable as a CSV (date, fajr, sunrise, dhuhr, asr, maghrib, isha, plus optional iqamah columns) instead of calculating times.
- **Works offline:** a service worker so the board keeps running when the Wi-Fi drops.
- **Seasonal iqamah:** different iqamah rules for date ranges (summer and winter).
- **Ramadan mode:** suhoor end and iftar countdown, Taraweeh time.
- **Eid times:** one-off Eid prayer times shown on the day.
- **"Prayer in progress" screen:** a quiet full-screen notice for a set number of minutes after each iqamah.
- **QR code:** an optional corner QR code for donations or the masjid website.
- **Config helper page:** a form that writes `config.json` for people who do not want to edit JSON.

## Guides
- Raspberry Pi kiosk set-up (auto-start Chromium full screen)
- Amazon Fire TV Stick set-up
- Android TV and smart TV browsers
